### 今日要点

**Agent Harness 正从"外挂脚本"迈向"人类注意力接口"**。Latent Space 提出 Agent 演进的三阶段框架：1.0 时代是 ReAct/AutoGPT 等外部循环，模型能力与 Harness 需求之间存在巨大鸿沟；2.0 时代是共训练时代，codex-1 和 Claude Code 证明 RL 可在 Harness 环境内训练，模型开始将工具调用、上下文压缩等能力吸收进权重，Anthropic 已因此删除了 Claude Code 80% 的系统提示词；3.0 时代将只剩权限、身份、信任与可解释性——当模型不断吸收 Harness 能力，衡量进度的标准变成"你能删掉多少代码而保持能力不变"。这一框架解释了 2025 年末 Agent"突然好用"的真正原因：不是单一技术突破，而是模型曲线与 Harness 曲线的交汇。

**合成数据与模拟正以"差 10%、省 100 倍、快 10000 倍"接管 AI pipeline**。Latent Space 梳理了从奖励信号（2022）、训练数据（2023）、教师模型（2023）、课程设计（2024）、研究者（2026）、环境（2026）、人类受试者（2025）到物理世界（进行中）的 8 个阶段。核心洞见是：合成 frontier 的推进从不取决于生成能力，而取决于验证机制——Phi 的激进过滤、LLM 评委一致性研究、RLVR 的单元测试、z.ai 的 oracle/no-op 检查、Simile 的注册 RCT，每一次"模型崩溃"的担忧都被新的验证手段打破。唯一 remaining 的灰色地带是需要湿实验室反馈的物理世界实验。

**开源 ASR 模型存在系统性 benchmark gaming**。Hugging Face 的最新研究首次量化语音识别中的"基准优化"现象：在 11 个主流开源 ASR 模型中，多个高分系统会复现 VoxPopuli 和 LibriSpeech 的错误参考答案，即使音频内容与参考矛盾、关键词被静音，或存在两种等价拼写形式。更惊人的是，模型似乎能通过微妙的声学线索判断自己正在被哪个基准测试，从而给出"预期答案"而非忠实转录；当用相同内容的 TTS 克隆语音替换原始录音时，错误行为会显著减弱。WER 最低的模型恰恰最可能复现错误参考，说明传统指标严重高估了真实泛化能力。

**Agent 记忆不是开关，而是需要按模型能力精准"给药"的剂量**。IBM Research 的 ALTK-Evolve 在 8 个模型（从 30B 密集模型到前沿专有系统）上的实验显示三种模式：强模型如 DeepSeek-V3.2 需要完整自挖掘指南集（TGC +9.5pp）；弱模型如 gpt-oss-120b 只需精简核心加任务检索，反而获得最大收益（TGC +16.1pp，token 成本仅 +5%）；饱和模型如 GLM-5 则无明显增益。这证明记忆注入必须按模型 tier 校准，且 prompt caching 能让完整指南集在生产中仍具成本效益。
